Website Sistem Manajemen Skincare adalah aplikasi berbasis web yang dibuat untuk membantu mengelola data produk skincare secara lebih terstruktur dan efisien. Sistem ini memudahkan pengelolaan stok, pemantauan produk, serta interaksi pengguna dalam satu tampilan yang terorganisir.
Fitur-Fitur Website yang ada:
1. Navbar, Sebagai navigasi utama untuk berpindah ke bagian seperti Home dan Tambah Produk.
2. Hero Section, Menampilkan judul sistem dan deskripsi singkat sebagai pengenalan website skincare.
3. Dashboard Statistik, Menampilkan ringkasan data seperti: Total Produk, Produk Tersedia, dan Produk Habis. Berfungsi untuk melihat kondisi stok secara cepat.
4. Daftar Produk Skincare, Menampilkan informasi produk seperti: Nama produk, Harga, Stok, serta tombol aksi seperti Beli dan Tambah ke Wishlist.
5. Form Input Data Produk, Digunakan untuk menambahkan data produk skincare baru ke dalam sistem.
