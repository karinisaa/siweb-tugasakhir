Website Karina Beauty ini digunakan untuk mengelola data dan aktivitas produk skincare secara digital. Melalui website ini, pengguna dapat melakukan pembelian yang otomatis mengurangi jumlah stok, menyimpan produk ke dalam wishlist, serta mengatur tampilan dark mode atau light mode sesuai preferensi. Semua interaksi dilakukan secara langsung tanpa reload halaman karena menggunakan JavaScript.
Fitur-Fitur Website yang ada 
1. fitur Dark Mode yang bisa diaktifkan lewat tombol di navbar, dan pilihannya disimpan di localStorage sehingga tetap aktif meskipun halaman di-refresh.
2. fitur Beli Produk akan mengurangi stok secara otomatis setiap kali tombol diklik. Jika stok habis, tombol akan nonaktif agar tidak bisa dibeli lagi.
3. fitur Wishlist menyimpan nama produk ke sessionStorage, menampilkan jumlah item di navbar, dan menampilkannya dalam bentuk modal saat tombol wishlist diklik.
